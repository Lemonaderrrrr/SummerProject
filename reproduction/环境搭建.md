# 阶段 A · 环境搭建指南

> 目标:从零到**跑通一个预训练 OpenVLA 在 LIBERO 上的推理**(里程碑 M1)。
> ⚠️ 下面命令基于官方仓库/RCIC 文档(2026-06 查证),**版本与确切参数以官方 README 为准**;遇到冲突按官方走。链接见文末。

---

## 第 0 步 · 申请 UCI HPC3 账号(先做,等审批)

用你的 **UCInetID 邮箱**发邮件给 **hpc-support@uci.edu**。模板:

```
To: hpc-support@uci.edu
Subject: HPC3 account request

Hi,

I'd like to request an HPC3 account to run GPU jobs for a summer
research project on vision-language-action (VLA) models.

UCInetID: <你的 UCInetID>
Name: <你的名字>
Purpose: fine-tuning / inference of open-source VLA models (OpenVLA, openpi) in simulation

Thank you!
```

- 免费一次性 **1000 core-hours** + 可用 **`free-gpu`** 分区(任务可能被抢占,练手够用)。
- 想要更稳的 GPU 工时:找机器人/ML 方向 PI 挂靠,或选 CS175 拿课程 GPU 额度。

## 第 1 步 · 在 HPC3 上跑通一个 GPU 作业

登录后,用 `scripts/hpc3_gpu_job.slurm.example` 提交一个测试作业,确认能拿到 GPU:

```bash
sbatch reproduction/scripts/hpc3_gpu_job.slurm.example
squeue -u $USER          # 看作业状态
```
> ⚠️ 分区名 / GRES 写法(如 `--gres=gpu:A30:1` vs `--gres=gpu:1` + 约束)以 RCIC 文档为准,先用 `sinfo` 看可用分区。

## 第 2 步 · 装 OpenVLA 环境

OpenVLA 用 Python 3.10 + PyTorch 2.2:
```bash
conda create -n openvla python=3.10 -y
conda activate openvla
git clone https://github.com/openvla/openvla.git
cd openvla
pip install torch==2.2.0 torchvision==0.17.0 torchaudio==2.2.0
pip install -e .
pip install packaging ninja
pip install "flash-attn==2.5.5" --no-build-isolation   # 需要 GPU 节点上装
```

## 第 3 步 · 装 LIBERO + 下载评测 checkpoint

OpenVLA 的 LIBERO 评测在 `experiments/robot/libero/` 下,**跟着 OpenVLA 仓库的 LIBERO 说明走**(它会让你装 LIBERO 并装额外依赖):
```bash
git clone https://github.com/Lifelong-Robot-Learning/LIBERO.git
cd LIBERO && pip install -e . && cd ..
pip install -r experiments/robot/libero/libero_requirements.txt
```
> LIBERO 基于 robosuite + MuJoCo;四个任务套件:Spatial / Object / Goal / 10(Long)。

## 第 4 步 · 跑通推理评测(= 里程碑 M1 ✅)

OpenVLA 提供了在各 LIBERO 套件上 LoRA 微调好的 checkpoint,运行评测脚本会**自动下载**对应 checkpoint:
```bash
# 在 GPU 作业里跑(示例;确切脚本名/参数见仓库 README)
python experiments/robot/libero/run_libero_eval.py \
  --model_family openvla \
  --pretrained_checkpoint openvla/openvla-7b-finetuned-libero-spatial \
  --task_suite_name libero_spatial
```
**M1 达成标准**:仿真里能看到 OpenVLA 控制机械臂跑一个 LIBERO 任务并打印成功率。
记一下:推理延迟、显存占用、模型大小 —— 这是 P1 对比的第一组数据。

## 第 5 步(P1 起步)· 加上 π0 / openpi

openpi 用 `uv` 管理,自带 `pi0_fast_libero` 配置:
```bash
git clone https://github.com/Physical-Intelligence/openpi.git
cd openpi
# 按官方 README 用 uv 装依赖;推理/评测约需 ≥24GB 显存(A30 够)
uv run scripts/compute_norm_stats.py --config-name pi0_fast_libero
```
> π0 全量微调要 40–80GB(用 A100,或改 LoRA / 多卡);**推理评测 A30 24GB 就够**。
