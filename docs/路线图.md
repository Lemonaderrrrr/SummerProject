# 项目路线图(Roadmap)

> 这份文档是项目从「构思」到「交付」的完整 journey 总览,按阶段拆成任务。
> 每个阶段里的具体任务会做成 GitHub Issue 来认领和追踪。
> 项目主题确定后,阶段 4 及之后的任务会进一步细化。
